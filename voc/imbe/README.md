# IMBE vocoder (cfw/voc/imbe)

This is an IMBE 7200x4400 encoder and decoder for P25 Phase 1 full rate and YSF Voice FR (VW). It turns
8 kHz 16-bit PCM into 88 information bits per 20 ms frame and back. The bitstream follows
TIA-102.BABA: an mbelib decoder (ISC) reconstructs speech from this encoder's frames.

```
make test               # host tests (gcc): 23 checks; writes build/speech_{in,out}.raw (s16le 8 kHz)
make arm                # Cortex-M33 objects + size
./bench/run_bench.sh    # Cortex-M33 instruction count per frame (Renode)
```

## Files

| File | |
|---|---|
| `imbe.h` | API: `imbe_encode()`, `imbe_decode()`, `imbe_unpack()` (bits → parameters), `imbe_synth()` |
| `imbe_dec.c` | dequantisation + spectral enhancement (adapted from mbelib, ISC), synthesis and FFT (own) |
| `imbe_enc.c` | analysis + quantisation (own) |
| `imbe_tables.c/.h` | dequantisation tables, generated by `tools/gen_tables.py` from mbelib's `imbe7200x4400_const.h` (ISC notice kept) |
| `imbe_vocoder.h`, `cfw.mk` | platform-facing header name and build list (`IMBE_SRCS`, `IMBE_INC`) |
| `voc_imbe.c/.h` | cfw backend: `voc_imbe_encode/decode()`, `g_voc_imbe` (`cfw_vocoder_ops_t`, name "imbe", interoperable) |
| `tests/test_imbe.c` | host tests |
| `bench/` | bare-metal M33 benchmark (Renode) |

Frame bits are 88 bits packed MSB first in u-vector order (u0..u7). This is the output of
`p25_imbe_decode()` (cfw/proto/p25) and mbelib's `imbe_d`. FEC is not part of the vocoder.

## How it works

- **Decoder.**
  - Parameters: b0 → w0, L, K; b1 → V/UV per band; b2..b7 → gain vector (6-point IDCT); b8.. →
    higher-order DCT coefficients of 6 blocks. The log2 amplitudes are a residual on the previous
    frame's prediction (rho 0.4..0.7).
  - Then mbelib's spectral enhancement.
  - Synthesis (own, MCU friendly):
    - Voiced harmonics are phasor oscillators with a 50-sample crossfade between frames; the phase
      model is the standard's (psi/phi with random dispersion above L/4).
    - Unvoiced bands are a random-phase spectrum through a 512-point inverse real FFT: one 320-sample
      grain per frame, sine window, power-complementary overlap-add.
  - Bad frames (errs > 5, invalid b0) repeat the previous parameters; the 4th one in a row mutes.
- **Encoder.**
  - Analysis: one frame look-ahead (20 ms delay), DC blocker, 281-point Hamming window, 512-point FFT.
  - Pitch: normalised autocorrelation (by FFT) of the centre-clipped signal, with sub-multiple and
    continuity checks, parabolic refinement, then the best harmonic fit within ±1 b0 step. A single
    dominant tone is placed on a low harmonic (frequency error vs. harmonic number) and coded
    all-voiced, so no phase dispersion is added.
  - Amplitudes and voicing:
    - Voiced amplitude per harmonic: least-squares fit of the window spectrum.
    - Unvoiced amplitude: band energy as an equivalent sinusoid, divided by `IMBE_UV_GAIN`.
    - Voicing per 3-harmonic band: normalised fit error against a threshold. The threshold falls with
      frequency, rises with frame periodicity, has hysteresis, and weak bands follow the frame's
      periodicity.
    - Per-frame dynamic range is limited (48 dB speech / 36 dB tone), because the residual quantiser
      cannot follow deep nulls.
  - Quantisation:
    - Closed loop: residuals are taken against the decoder's own predictor, and the encoder runs
      `imbe_unpack` on its output.
    - Block DCTs and a 6-point DCT of the block means. G1 by the b2 codebook, G2..G6 and the
      higher-order coefficients uniform. All bit allocations come from the tables.
- **Scale.** PCM = 7 × model amplitude (mbelib). Unvoiced level is calibrated to mbelib's multisine
  synthesis (`IMBE_UV_GAIN` = 2.343), so cfw and mbelib decoders agree on loudness.

## Results (host tests and checks, 2026-11-20)

- **Dequantisation:** identical to mbelib 1.3.0 `mbe_decodeImbe4400Parms` on 16 191 chained random
  frames (scratch comparison, 0 mismatches). The test suite has 48 mbelib known-answer frames.
- **Tones** (encode → decode):

  | In | Out | SINAD | Level |
  |---|---|---|---|
  | 300 Hz | 299.1 Hz | 29 dB | −0.4 dB |
  | 440 Hz | 441.4 Hz | 28 dB | +0.2 dB |
  | 1011 Hz | 1010.5 Hz | 31 dB | +0.6 dB |
  | 1500 Hz | 1495.3 Hz | 30 dB | −0.5 dB |

  Frequency is quantised to harmonics of the b0 grid. Tones above ~2 kHz lose accuracy and level.
- **Speech-like signal** (3 synthetic vowels with pitch glides, fricative noise, silence):
  - log-spectral distance 4.2 dB voiced, 3.5 dB unvoiced;
  - voicing right in 77/77 voiced and 17/17 unvoiced frames;
  - pitch in range in all frames.
- **Cross-decoding:** this encoder's bits played through mbelib's own decoder give the same voiced
  quality (LSD 5.3 / 4.2 / 2.5 dB on /a/ /i/ /u/ for both decoders). mbelib's fricatives are louder
  (+5.5 dB), because it adds extra noise above 2.7 kHz.
- **Emulator two-radio loop** (`emu/txrx_loop.py --mode p25 --voc 2`, scratch firmware build with the
  imbe backend linked into voice.c): PASS. 440 Hz → 441.4 Hz, SNR 27.2 dB, firmware meter
  "AF 441.3Hz 27dB SINAD", IDs decoded. Also PASS with `--snr 12`.
- **FEC chain:** encode → `p25_imbe_encode` → 3 bit errors → `p25_imbe_decode` gives identical bits.
- **Cortex-M33** (Renode instruction count, -O2):

  | | Instructions per 20 ms frame | CPU at 120 MHz (CPI 1.0..1.5) |
  |---|---|---|
  | Encode | ~269 000 | 11..17 % |
  | Decode | ~141 000 | 6..9 % |

  Flash about 21 KB (12 KB tables). Static RAM about 7.7 KB plus the encoder (1.9 KB) and decoder
  (1.3 KB) states.

## Not verified / limits

- Not tested against a real P25 radio or a DVSI chip. There are no public, clearly licensed IMBE test
  frames, so none are included. Bitstream semantics are checked only against mbelib (tables and
  decode procedure).
- Absolute loudness and the voiced/unvoiced balance follow mbelib's conventions, not a measured
  real radio.
- Synthesis is not the standard's reference synthesis. The standard does not require bit-exact
  synthesis, but quality may differ from commercial decoders.
- Tested on synthetic speech only (no recorded speech corpus in the repo). PESQ was not available;
  the metric is log-spectral distance.
- Silence: there is no special silence frame. The encoder codes low-level noise (decoded floor
  ≈ −67 dBFS).
